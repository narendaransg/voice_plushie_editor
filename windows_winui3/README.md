# Voice Plushie Editor — Windows (WinUI 3)

Native Windows desktop build designed for:
- Smooth compositor animations and click-through DPI-aware KeyTip overlays
- Hands-free cursor hover, 4-way/timeline nudging, and two-stage drag-and-drop
- Clean single-process shutdown (no lingering overlays or stuck terminals)
- Shared `config/profiles` and `themes` assets from the repo root
